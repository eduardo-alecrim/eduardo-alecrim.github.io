# eduardo-alecrim.github.io

My portfolio, live at **https://eduardo-alecrim.github.io**. It's styled after Brasília's metro, which runs two lines: green and orange.

A plain static site with no build step: GitHub Pages serves the files as they are.

| File | What's in it |
| --- | --- |
| `index.html` | Every section, with the English text |
| `script.js` | The Portuguese text, the EN/PT toggle, the typed tagline and the scroll reveals |
| `styles.css` | Layout, colours and animations |
| `favicon.svg`, `og.png` | Tab icon and the preview image shown when the link is shared |

To change a text, edit it in `index.html`, and its Portuguese version in `script.js` under the same `data-i18n` key. To preview, open `index.html` in a browser.

The tech logos come from [Simple Icons](https://simpleicons.org) (CC0); the brands belong to their owners. With *reduce motion* turned on, the page shows everything still.
